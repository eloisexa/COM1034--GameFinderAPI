To create the following screens of our new feature we used Figma.

![Homepage](<Homepage.png>)
This is the homepage, note it is selected from the bar at the bottom. It contains the 'pick for me' button which causes a pop-up to show for that feature. It also contains a few categories of games, such as currently playing and previously played. It has a scroll bar on the side that would allow the user to scroll down to view other categories such as recommended games or friend activity (games that the user's friends on the system have played/been playing).

![Profile](<Profile.png>)
This is the profile page, where the user can view their profile; they can see their profile picture, username, game library, as well as some more recommendations based on their favourite (most played) genres. This page can be accessed by clicking on their profile picture in the top corner of the other screens, and helps give the app a personalised feel for the user.

![Search page](<Search_page.png>)
This is the search page, which can be accessed via the options at the bottom of the page. Here the user can search for a game or another user to become friends with them. It also shows trending games to help give the user more options and suggestions on what to play.

![Wishlist](<Wishlist.png>)
This is the wishlist. It shows games the user has added to it and will prioritise showing the games that are on sale. The user also has the ability to view more information about the game, as well as the options to add or remove the games from their wishlist.

![You should play](<You_Should_Play.png>)
This is the first pop-up that comes up when the user selects the 'pick for me' button. It has a slider to select the amount of time the user has to play, which is very useful in helping users decide what games to play based on the length of time they wish to be playing for, providing a more personalised way of searching for games. There is also a few feelings to select from that help narrow down the options that are generated.

![You should play (generated)](<You_Should_Play_generated.png>)
Finally, this is the screen that shows once the user has selected the generate button. It shows the games profile and name which the user can select to be taken to the games' page.
