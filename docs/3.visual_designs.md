![Homepage](<Homepage.png>)
This is the homepage, note it is selected from the bar at the bottom. It contains the pick for me button which causes a popup to show for that feature. It also contains a few categorys of games, such as currently playing and played. It has a scroll bar on the side that would let the user scroll downt to view other categorys such as recommended or friend activity.

![Profile](<Profile.png>)
This is the profile page, where the user can view their profile: they can see their profile picture, username, game library, as well as some more recommendations based on their favourite (most played) genres. This page can be accessed by clicking on their profile picture in the top corners of the other screens, and helps give the app a personalised feel for the user.

![Search page](<Search_page.png>)
This is the search page; it can be accessed via the options at the bottom of the page. Here the user can search for a game or another user to friend them. It also shows trending games to help give the user more options.

![Wishlist](<Wishlist.png>)
This is the wishlist. It shows games the user has added to it and will prioritise showing the games that are on sale. The user also has the ability to view more information about the game, as well as the options to add or remove the games from the list.
