# Architecture & Data Model

## 1. System Architecture

<!-- Description of the overall system structure and main components. Include an architectural diagram to illustrate how the components interact. -->

* User can interact with features provided
* Wishlist service:
    * Creates and manages wishlist
    * Add/remove games retrieved from database
    * Consists of Wishlist and WishlistItem
* Game generator:
    * Provides recommendations to user for games to play, retrieved from database
    * Uses AI tools to generate games recommended based on user preferences and history, which will be fetched from the database
* Game completion:
    * Queries database to see if user has played a game previously, and relays/displays this on the screen to the user
